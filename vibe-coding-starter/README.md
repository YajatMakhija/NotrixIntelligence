# Notrix Intelligence

Marketing website for Notrix Intelligence: company knowledge connected in Slack, with customer-controlled data storage and sourced answers.

## Local development

```bash
npm install
npm run dev
```

The development server runs at `http://localhost:6006`.

## Main routes

- `/` — landing page
- `/product` — product overview
- `/docs` — pilot documentation
- `/security` — security model
- `/privacy` — privacy information
- `/terms` — terms of use
- `/notrix/editor` — local layout editor
